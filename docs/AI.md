# AI

## AI provider

Основний AI provider - Gemini через `GEMINI_API_KEY`.

Якщо ключ заданий, `/api/entries` викликає Gemini і генерує персональну відповідь на основі:

- тексту конфлікту;
- причини злості/суму;
- пам'яті Саші;
- пам'яті Марини.

## Fallback

Якщо ключа нема або API недоступний, застосунок повертає локальну теплу відповідь, щоб основний сценарій не ламався.
